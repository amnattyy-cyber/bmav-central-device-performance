# BMAV Device by Brand Dashboard

Interactive infographic dashboard for BMA V - Central device performance in August 2026.

## Dashboard controls

- Net Amount (default) or Quantity
- Brand and target-eligible shop
- Sales date
- Daily or month-to-date (MTD)

The source snapshot was generated from the BMAV target and sales workbooks. A downloadable Excel dashboard is included in `public/`.

## Local development

```text
pnpm install
pnpm run dev
```

## Validation

```text
pnpm run lint
pnpm run build
```
